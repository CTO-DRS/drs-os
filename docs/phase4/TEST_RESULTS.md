## 3. Accounting correction vs. Phase 3 record (explicit, per task §2)

Phase 3 reported "188" core tests. Phase 4 found that the JUnit console
runner's `--scan-classpath` scanned the entire classpath, so the
engine-core and settings-core steps **re-ran foundation's 25 tests**
(104 = 79+25, 41 = 16+25). True unique count: **138** (25+79+18+16), all
passing on both the kotlinc runner and the Gradle path. The runner was
fixed (`--scan-classpath "$out"`); recorded as defect D-9 in
BUILD_RESULTS.md. Both the corrected number and the discrepancy are
stated here rather than silently reconciled.

## 4. Layer 3/4 — exact blockers and future-run commands

`/dev/kvm` does not exist in this sandbox and x86_64 emulator images
require KVM (2 vCPU / 3.9 GiB RAM also far below emulator comfort).
Nothing was faked; no screenshots exist. On a KVM-capable host:

```bash
sdkmanager "emulator" "system-images;android-35;google_apis;x86_64"
avdmanager create avd -n drs-test -k "system-images;android-35;google_apis;x86_64"
emulator -avd drs-test &
adb wait-for-device
gradle -p packages/apps/DRSAutomation :app:connectedDebugAndroidTest
# NOTE: connectedTest source sets are NOT yet authored — authoring them
# is Phase 5 work (TEST_PLAN T-16..T-20). Ad-hoc verification:
adb install -r packages/apps/DRSSettings/app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.drs.os.drssettings/.MainActivity
adb exec-out screencap -p > evidence/settings-launch.png
```

Privileged capabilities (verified-boot state, platform keys) remain
UNAVAILABLE-by-design inside a regular app; on-device evidence for them
requires the platform integration phase, not an emulator.

## 5. Robolectric — NOT RUN (deliberate)

Robolectric-based Compose UI tests would run on the JVM without an
emulator. They were **not attempted** in Phase 4: the phase's core
objective (real builds + honest defect correction) was achieved
otherwise, and adding a Robolectric dependency + android-all runtime
download mid-phase would expand scope without review. Recorded as the
first Phase 5 recommendation; until then the label is NOT RUN, not
BLOCKED and not PASS.
